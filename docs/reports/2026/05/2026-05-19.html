Sigma 发布面向 AI coding agents 的数据建模能力

2026-05-18T0SigmaData Modeling Skills for AI AgentsOpenAI CodexClaude CodeCursorSnowflake Cortex Code
  • 公告明确点名 OpenAI Codex、Claude Code、Cursor 和 Snowflake Cortex Code，说明 BI/analytics 平台开始把 agent 作为数据建模入口，而不只作为问答层。

Zignal Labs 推出 Zignal AI，面向任务系统和 agent-driven workflows 输出结构化情报

2026-05-18T1Zignal LabsZignal AIZENPeraton IRISagentic reportingmulti-agent workflows
  • Zignal AI 的目标不是提供更多原始公开数据，而是输出叙事检测、地理定位视觉情报、聚类事件、告警和结构化 intelligence artifacts。
  • 发布稿称该能力可通过 ZEN、API、合作伙伴平台或客户自有系统接入，并已用于 Peraton IRIS 等 agent-driven workflow 场景。
  • 这代表 agent 系统的一个现实约束：很多高风险场景需要上游信息形成层先做过滤、富集、验证和结构化，不能让 agent 直接吞原始噪声。

提示词与规则迭代建议

  1. 同一合作事件有双方官方发布页时，当前 schema 的 main_items 只有单一 url 字段，容易诱导拆成两条来保留两个来源。

    预期收益：增加 optional additional_urls 后，可以合并同一事件并保留双方一手来源，减少重复条目和证据丢失。

  2. 官方首页和搜索结果会把旧文章或预告卡片排在前面，若只看首页摘要容易误判为今日发布。

    证据：Google Developers 首页和搜索结果在 2026-05-19 显示 Google I/O 与 Gemini 相关卡片，但详情页日期多为 2026-02 或 2026-04，Mistral 3 页面也缺少稳定日期交叉确认。

    预期收益：明确要求以详情页 published date、dated changelog、RSS 或 commit 为准，可减少首页卡片造成的旧闻入选。

  3. GitHub Changelog 同日会出现多条同产品小更新，当前合并规则没有要求列出被合并的子链接。

    证据：2026-05-18 GitHub Copilot 同日包含 Actions 一键修复、低成本模型、Web 上下文问答、配置 API、Spaces API 和远程控制等多条更新；主体只能挂 GitHub Changelog 汇总页。
