今日主线

  1. Google I/O 2026 把 Gemini 3.5、Gemini Omni 和 Antigravity 放到同一条 agent 叙事线上 重大 topic|primary
  • 发生了什么：Google 在 I/O 2026 开发者主题演讲中发布 Gemini 3.5 系列，并升级 Antigravity 这个 agent-first development platform，把模型、IDE、AI Studio 与 agent 编排放进同一套开发链路。
  • 为什么值得看：Google 官方 I/O 汇总页同时提到 Gemini Omni、Gemini 3.5 Flash、Search 信息 agent、Gemini Spark 和 Daily Brief，显示发布重点已经从单点模型转向跨产品 agent 体验。
  • 来源： Google Developers Blog
  1. GitHub Copilot 在 VS Code 中推出按任务自动路由模型 重大 topic|primary
  • 发生了什么：GitHub Changelog 显示，Copilot auto model selection 现在会基于任务、模型健康度和使用情况，把 VS Code 中的请求路由到更合适的模型。
  • 为什么值得看：组织侧需要关注的是可观测性、成本控制和策略透明度：自动路由是否能解释为什么某个任务用了某个模型，会影响企业落地。
  • 来源： GitHub Changelog
  1. Amazon SageMaker AI endpoints 增加 OpenAI-compatible API 重大 topic|primary
  • 发生了什么：AWS 宣布 SageMaker AI real-time inference endpoints 支持 OpenAI-compatible API，让使用 OpenAI SDK、LangChain 或 Strands Agents 的应用通过改 endpoint URL 调用 SageMaker 模型。
  • 为什么值得看：对企业 AI 平台团队来说，SageMaker 现有治理、部署和监控能力可以更容易接入 agent 与 LLM 应用框架。
  • 来源： AWS Machine Learning Blog
  1. Claude Managed Agents 增加 self-hosted sandboxes 与 MCP tunnels 重大 topic|primary MCP: 7d 9x/4d enterprise agent governance: 7d 7x/4d
  • 发生了什么：Anthropic 在 Claude Managed Agents 中加入 self-hosted sandboxes 和 MCP tunnels，把 agent loop 与工具执行环境、私有 MCP 访问边界拆开。
  • 为什么值得看：这类设计把 agent 执行从纯云端封装推进到企业可控基础设施，安全边界、凭证隔离和审计会成为 Managed Agents 竞争的核心。
  • 来源： Claude Blog
  1. Vercel AI Gateway 上线 Gemini 3.5 Flash 重大 topic|primary
  • 发生了什么：Vercel Changelog 显示 Gemini 3.5 Flash 已可通过 AI Gateway 使用，并给出 AI SDK 中的 `google/gemini-3.5-flash` 模型标识。
  • 为什么值得看：对前端和全栈团队来说，模型上新速度会越来越取决于 gateway 与 SDK 的适配，而不是每个应用单独接 provider。
  • 来源： Vercel Changelog
  1. Hugging Face 与 Ai2 同日给出小型 reranker 和地球科学模型更新 重大 topic|primary
  • 发生了什么：Hugging Face 发布 Ettin Reranker family，Ai2 发布 OlmoEarth v1.1；两者都指向一个趋势：专业任务模型继续沿着更小、更可部署、更可验证的方向推进。
  • 为什么值得看：Ai2 的 OlmoEarth v1.1 面向地球观测场景，官方页同时给出模型、技术报告和代码入口，适合作为专业领域开放模型跟踪对象。
  • 来源： Hugging Face Blog / Ai2 Blog
