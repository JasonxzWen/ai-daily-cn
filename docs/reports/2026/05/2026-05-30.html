其他信号

  1. 发布 Rosalind Biodefense 并开放 GPT-Rosalind 可信访问 重大（2026-05-29，T0）
  • OpenAI 将 GPT-Rosalind 放在受控伙伴访问链路中，重点不是聊天产品，而是生物防御机构和可信开发者的专业工作流。
  • 文章列出的任务包含 epidemiological modeling、early detection、screening 和 response preparedness，说明模型能力被包装为可审计的公共卫生工具。
  • 对部署团队来说，关键约束是访问对象、任务范围和支持机制，而不是模型名称本身；后续应跟踪伙伴案例是否披露评测方法和边界。
  1. 宣布 Nano Banana 2 与 Nano Banana Pro GA 重大 enterprise agent governance: 7d 3x/3d（2026-05-29，T0）
  • 企业平台路径强调商业框架和 SLA，适合需要治理、审计和品牌素材生产链路的客户。
  • Nano Banana 2 支持视频文件作为输入提示仍处于 preview；1K/2K 输出 GA，4K 输出仍是 preview，生产场景需要按功能状态拆分开关。
  • Gemini API 路径为开发者提供更直接的试用入口，但官方明确它不由企业 SLA 覆盖，不能与企业平台承诺混为一谈。
  1. 完成 650 亿美元 Series H 融资并列出算力伙伴 重大（2026-05-28，T0）
  • 这篇官方公告把融资、收入、内存供应和云端算力放在同一页，说明 Anthropic 正把模型发布节奏与基础设施承诺一起讲清楚。
  • Amazon 最高 5GW 的 Project Rainier 容量、Google/Broadcom 5GW TPU 协议和 SpaceX Colossus GPU 容量共同构成后续 Claude 供给的关键背景。
  • 对企业采购来说，Claude 同时覆盖 AWS、Google Cloud 和 Azure 的叙述，降低了只押单一云入口的必要性，但真实可用区域、价格和配额仍要按各云文档核验。

ChatGPT release notes: GPT-5.5 Instant 更新与旧模型退场日期

值得关注ChatGPT 产品更新与模型生命周期

要点 2
这里最值得产品团队核对的是界面行为：复杂写作和代码将更多以聊天内代码块完成，而不是自动进入 canvas。

Claude Opus 4.8 is now available on AWS

值得关注Bedrock 上的 Claude Opus 4.8 集成

AWS 这篇文章不是再宣布一次模型发布，而是把 Claude Opus 4.8 在 Bedrock 与 Claude Platform on AWS 两条路径中的接入方式写成可执行说明。

要点 2
它列出 Bedrock 控制台试用、Anthropic Messages API 通过 bedrock-runtime 调用、Converse API 调用、模型 ID、权限前提和区域可用性。
要点 3
对已经在 Bedrock 做多模型网关的团队，文章的价值在于把模型能力描述和接入细节放在同一处：可以直接核对 IAM、SDK、区域、调用 API 和是否需要 Claude Platform 原生体验。

A New Era of Innovation: Google Research at I/O 2026

要点 2
