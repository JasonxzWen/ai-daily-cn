OpenAI 与 Malta 推出面向全体公民的 ChatGPT Plus 和 AI literacy 计划

2026-05-16T0OpenAIMaltaChatGPT PlusAI for AllOpenAI for Countries
  • 课程由 University of Malta 开发，目标是帮助公众理解 AI 能做什么、不能做什么，以及如何在家庭和工作中负责任地使用；完成课程后可获得一年 ChatGPT Plus 访问权限。

OpenAI 披露 Databricks 将 GPT-5.5 用于企业 agent 工作流

2026-05-15T0OpenAIDatabricksGPT-5.5CodexAgentBricksAgent Supervisor API
  • OfficeQA Pro 聚焦 scanned PDFs、legacy files、long-context documents 中的 parsing、retrieval 和 grounded reasoning；这些场景会把早期抽取错误放大到后续 agent 决策。

xAI 允许 Grok 订阅直接接入 Hermes Agent

2026-05-15T0xAIGrokHermes AgentNous ResearchOAuthSuperGrok
  • 官方说明该连接在每个订阅 tier 上可用；用户在 `hermes model` 中选择 xAI Grok OAuth 后，通过浏览器登录，再启动 Hermes TUI。
  • Hermes Agent 的定位是 persistent、自改进、可连接消息平台并保留长期记忆的本地/服务器 agent；Grok 订阅接入让消费者订阅模型进入开源 agent runtime，而不是只作为官方 App 内能力存在。
  • 这类 OAuth subscription provider 会改变开源 agent 的部署边界：模型账户、媒体生成、长期记忆、工具调用和本地文件权限集中到一个运行时，权限范围和隔离策略需要更明确。

Palantir Global Branching 从 2026-05-18 起进入 GA，覆盖 AIP Logic 等工作流

2026-05-18T0PalantirFoundryAIP LogicGlobal BranchingWorkflow LineageOntology
  • GA 覆盖 transforms、TypeScript v1 functions repositories、Pipeline Builder、Ontology、Workshop、AIP Logic 和 Object Views；Workflow Lineage 也已支持 Global Branching。
  • 分支工作流包括创建或访问 branch、修改资源、从 Main 引入更新并解决冲突、保护资源、定义 approval policies、查看 branched resources 和在 checks 通过后 merge。
