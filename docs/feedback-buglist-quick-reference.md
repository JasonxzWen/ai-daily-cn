# Feedback Buglist Quick Reference

This file is the human-readable companion to `config/feedback-ledger.json`. Treat the JSON ledger as the machine contract and this document as the pre-work scan list.

Current precedence: `feedback/p1-curated-three-layer-homepage` controls the accepted target. It separates internal repo-safe raw observations, a deterministic low-threshold persistent pool, and a high-threshold curated homepage. `feedback/p1-lossless-public-signal-stream` is closed as the default-homepage target and remains only as current-runtime/raw-lineage/legacy-archive evidence until the phased migration passes. Older rows remain implementation history unless the new target explicitly reuses them.

## Mandatory Flow

- Before any repository modification, review `config/feedback-ledger.json` and this quick reference.
- Record the applicable items in `tasks/current-task.md` under `Feedback Ledger Review`.
- Before handoff, record the concrete checks performed under `Regression Self-Check`.
- If the user confirms a new issue should persist, add or update a P1 ledger item with scope files, a validation command covered by `corepack pnpm run validate`, and an existing test or runtime gate. Also update this quick reference.
- If a feedback item cannot yet be bound to a test or gate, mark it as a session-local note instead of claiming durable memory.
