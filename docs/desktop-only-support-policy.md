# 桌面端唯一支持政策

ai-daily-cn 只维护桌面端产品体验。唯一规范验收视口是 `1280x900`，输入方式是鼠标与键盘。

## 不支持范围

- 手机、平板、窄屏和触摸专用布局；
- 基于宽度的响应式 breakpoint、移动端折叠/堆叠分支和触摸专用滚动；
- 移动设备、移动浏览器或窄屏截图/E2E/页面质量门禁；
- 为移动适配而添加的 viewport meta、模板、生成器或公开产物。

后续不得以“顺手兼容”“desktop-first”或“暂时 deferred”为由重新引入上述能力。若产品范围改变，必须重新立项、明确成本并由用户做新的范围决策。

## 仍然保留

- `prefers-reduced-motion`、键盘焦点、语义结构、桌面端横向溢出和可访问性检查；
- 正文 `max-width`、桌面内容密度和普通浏览器兼容；
- 新闻正文、历史审计/复盘和外部信源快照中的移动端事实；
- React、Astryx 等第三方依赖内部的通用 touch/pointer/响应式兼容。
- 浏览器协议中用于明确关闭设备模拟的必填参数（例如 CDP `mobile: false`）。

后三类只是事实证据或依赖实现细节，不代表本项目设计、维护、测试或承诺移动端支持。

## 执行门禁

- Web、日报、运营页、官方博客和交互报告只在 `1280x900` 做浏览器验收。
- `tests/adc-visual-contract.test.js` 的 `desktop-only` 守卫阻止项目自有 width breakpoint、viewport meta、移动验收视口和触摸滚动重新进入受管源文件。
- 生成公开站点后，必须确认项目自有 CSS 与 HTML 没有重新生成移动端逻辑；第三方 bundle 例外不得被当作验收证据。
