# ADC Character v1 Prompt

Create an original ADC brand character for a desktop-only AI news data product.

Style constraints:

- black-and-white rough ink line art
- rounded face geometry with simple glasses
- sparse hatching and visible hand-drawn stroke variation
- paper-toned background only
- small `ADC.` identity label

Do not copy third-party illustration IP or user-provided samples directly.
Do not add color palettes beyond ink and paper tones.
Do not make the homepage illustration-first; the asset supports the data product.
