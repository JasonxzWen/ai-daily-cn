# ADC Character v1 Decision

## Accepted

- Original black-and-white rough-line observer character.
- Glasses and paper label reinforce the ADC identity without adding a new mascot system.
- Paper-toned background matches the existing ADC homepage surface.

## Rejected

- Direct reuse or tracing of user-provided or third-party illustration samples.
- Full-color decorative character variants.
- Remote or embedded raster images inside the SVG.

## Usage

- Primary source asset: `apps/web/public/assets/adc-character.svg`.
- Generated public asset: `docs/assets/adc-character.svg`.
- Current surface: React homepage hero panel.

## Rights

- Original ADC-derived asset.
- No third-party illustration IP copied into the source SVG.
- Future variants must keep prompt, decision, and manifest records in this directory.
