# Current Task

## Goal

Implement the first version of AI daily navigation and trend tracking as a site-index layer.

## Status

Implemented and validated.

## Decisions

- Trend tracking is a derived site index, not a field written back into daily `reports-data` JSON.
- Controlled vocabulary is the primary signal source.
- Vocabulary is split into `topics` and `entities`.
- Thresholds are conservative: `watching`, `active`, and `hot`.
- Trend tags are rendered only on `main_items` and `github_trending`.
- `projects`, `builder_observations`, `hot_blogs`, and `model_releases` can contribute to trend counts, but do not receive inline tags in v1.
- Trend controlled vocabulary loading is fail-fast: missing, unreadable, invalid, or empty `config/trends.json` must stop the build instead of producing an empty trend index.

## Scope

- Add `config/trends.json`.
- Add `schemas/trends.schema.json`.
- Add `src/trends.js` for deterministic trend-index generation.
- Generate `docs/trends.json` during `npm run build`.
- Add homepage trend overview and year/month/week navigation.
- Add a daily-report hero link back to the navigation page.
- Inject trend annotations into effective-interact rendering without mutating report JSON.
- Cover the feature with unit, integration, and E2E tests.

## Non-goals

- Do not create per-topic detail pages in this version.
- Do not use an LLM to rewrite or classify historical reports.
- Do not publish, commit, push, or change automation settings.
- Do not write trend fields into `reports-data/**/*.json`.

## Acceptance Criteria

- `docs/trends.json` is schema-validated and generated by build.
- Repeated builds do not rewrite `trends.json` when inputs are unchanged.
- Homepage shows a trend overview when active/hot trends exist.
- Homepage shows navigation grouped by year/month/week.
- Daily report pages include a `日报导航` entry.
- Trend tags appear only in `main_items` and `github_trending`.
- Historical report JSON and published `docs/data` JSON are not polluted with trend fields.
- Missing or invalid trend vocabulary fails with a `PublisherError` before `docs/trends.json` is written.
- `npm run validate` and `node scripts/harness-validate.mjs` pass.
