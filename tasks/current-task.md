# Current Task

## Goal

Retry publishing accumulated AI daily report artifacts after syncing the remote trend-index update.

## Status

In progress. SSH fetch now works; `publish:dry-run` stopped because `origin/main` is ahead by the navigation/trend-index commit. Local 2026-06-01 artifacts were committed before merging remote changes.

## Decisions

- Preserve generated daily artifacts for 2026-05-30, 2026-05-31, and 2026-06-01.
- Do not use stash, reset, force-push, or overwrite remote/user changes.
- Merge `origin/main` normally, resolve conflicts explicitly, rebuild with the merged renderer/trend-index code, then validate and publish.
- API fallback is reserved for local `.git` metadata/write failures with a usable token; the current path is normal Git merge/push.
- Trend tracking is a derived site index, not a field written back into daily `reports-data` JSON.
- Controlled vocabulary is the primary signal source.
- Vocabulary is split into `topics` and `entities`.
- Thresholds are conservative: `watching`, `active`, and `hot`.
- Trend tags are rendered only on `main_items` and `github_trending`.
- `projects`, `builder_observations`, `hot_blogs`, and `model_releases` can contribute to trend counts, but do not receive inline tags in v1.
- Trend controlled vocabulary loading is fail-fast: missing, unreadable, invalid, or empty `config/trends.json` must stop the build instead of producing an empty trend index.

## Scope

- Commit local publisher-managed 2026-06-01 artifacts.
- Merge `origin/main` trend-index changes into local `main`.
- Resolve handoff Markdown conflicts without dropping either side's relevant state.
- Rebuild docs and `docs/trends.json`.
- Run `npm run validate`, harness validation, publish dry-run, real publish, and Pages verification.

## Non-goals

- Do not reset, force-push, stash, or overwrite user changes.
- Do not change remote GitHub Pages settings.
- Do not use API fallback unless the failure is a `.git` not-writable case and credentials are available.
- Do not create per-topic detail pages in this version.
- Do not use an LLM to rewrite or classify historical reports.
- Do not write trend fields into `reports-data/**/*.json`.
